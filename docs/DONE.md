# Definition of complete: status

The scope is **2 levels** (user decision, 2026-10-13). Levels 3–6 show as "under construction" in the sticker book.
Evidence comes from `tools/run_tests.sh` (ALL PASS), screenshots in `docs/shots/`, and bot logs in `docs/bot_level*_*.json`.

- [x] **Boots to a title screen with sound; one press starts.** Evidence: `docs/shots/title.png`. The title plays `music_title`; Fire/Enter on ▶ starts the next uncleared level.
- [x] **Levels playable start to finish, with checkpoints and an ending** (2 of 2 in scope). Evidence: bots finish both levels; checkpoints are at 0/680/1360/2040 m (L1) and 0/500/1000/1500 m (L2). The ending (`docs/shots/ending.png`) plays after the last built level, then the credits card, then the title.
- [x] **Sticker book, icons only:** cleared stars, orb diamonds, 3 ship colours (unlocked after L1 and L2 in this scope). Evidence: `docs/shots/book.png`.
- [x] **Pause from gameplay; restart and return work.** Evidence: `docs/shots/pause.png`. ▶ resumes, ↻ goes to the last checkpoint, 📖 goes to the book, and the book's 🏠 goes to the title. Keyboard R: tap = checkpoint, hold 1 s = whole level. Focus loss pauses.
- [x] **Parent menu:** volumes, speed, retro, fullscreen, invert, learn-mode rebinding, deadzone, reset controls, reset save (2 s hold), credits, language (en/es), quit. Evidence: `docs/shots/parent.png`.
- [x] **Rebinding for keyboard and unknown pad.** Evidence: the `--test` self-test learns a raw pad button as FIRE and a raw axis as LEFT (including menu mirroring), then resets. The menu shows live axis and button values. *Not tested with a physical PS2 adapter, which needs your playtest.*
- [x] **Save/load survives deleted, corrupt and wrong-typed files.** Evidence: the `--test` self-test (PASS). Writes are atomic (temp file + rename).
- [x] **Audio:** a music loop per biome plus title and ending, all effects, an engine bed and a limiter. Evidence: `docs/build_report.json`. All peaks are ≤ −9 dBFS (effects ≤ −10, engine −28), loop seams are < 0.005, and loops are an integer number of bars.
- [x] **Good and bad bots finish every level with no script errors.**

  | L1 | ok, 0 bumps, 20/20 popped, 157 s | ok, 31 bumps, 0 stalls, 181 s |

- [x] **60 fps.** Evidence: `docs/frametime_windows_level1.json`. The Windows build on an RTX 4060 averaged 16.72 ms with a 16.82 ms p99 (vsync-locked, no spikes) over the whole of Level 1. On Mesa software rendering it averages 8.1 ms with a 9.9 ms p99 (`docs/frametime_level*.json`). Everything loads before the first frame.
- [x] **Exported build runs on the developer's OS.** `build/windows/SkySkimmers.exe` is a single file with the pck embedded. It was launched natively from WSL interop and completed Level 1. *A literal double-click from Explorer is part of your playtest.*
